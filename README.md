# NumPy 🧮

A hands-on learning repository for **NumPy**, the fundamental Python library for numerical computing.

This repository contains my notes, examples, and practice code as I learn NumPy step by step.

## 📂 Topics Covered

Here is a breakdown of the concepts covered in this repository, mapped to their respective scripts:

- **Array Basics & Creation**: `main.py`
- **Data Types & Typecasting**: `DtypeAndTypecasting.py`
- **Indexing & Slicing**: `Indexing.py`
- **Reshaping & Manipulating Arrays**: `reshape_Manipulating.py`
- **Mathematical Operations**: `mathsOps.py`
- **Broadcasting & Vectorization**: `broadcasting_vectorization.py`
- **Array Modification**: `modification.py`
- **Handling Missing Values**: `missingValue.py`
- **Working with Datasets**: `dataset.py`

## 🚀 Getting Started

1. Clone the repository.
2. Create a virtual environment (optional but recommended).
3. Install NumPy:
   ```bash
   pip install numpy
   ```
4. Run individual scripts to see the examples in action!
